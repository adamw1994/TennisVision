# Ręczne oznaczenia uderzeń

Te pliki zawierają czasy uderzeń wskazane przez użytkownika podczas oglądania
próbek. To dane referencyjne do zachowania, a nie raporty generowane przez program.

- `Wojtek1set-2min.reference.csv`: komplet 13 poprawnych uderzeń oznaczonych
  w `Wojtek1set-2min.mp4`.
- `Wojtek1set-2min2.partial-reference.csv`: częściowe oznaczenia drugiej próbki,
  `Wojtek1set-2min2.mp4`. Pozostałe czasy nie zostały jeszcze ocenione.

Czasy podano w sekundach od początku odpowiedniej próbki. Oznaczenia drugiej
próbki są przybliżone; np. ręczne 3,35 s odpowiada detekcji około 3,36 s.
Filmy źródłowe pozostają w `C:\TennisSamples`.
